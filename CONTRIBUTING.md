# Working with ReparaLab

ReparaLab is maintained as a portfolio project and a starting point for independent adaptations. If you want to customize it for a repair shop, create your own repository using the GitHub template or fork it, then make changes there. You do not need to submit those changes to this repository.

This repository does not accept pull requests for business-specific features, branding, or data. Opening a pull request does not grant write access or guarantee that a change will be merged. The maintainer decides which changes, if any, become part of ReparaLab.

Follow [LICENSE](LICENSE) and preserve the applicable copyright and [third-party notices](THIRD-PARTY-NOTICES.md) when sharing an adaptation. Before distributing a build, review the licenses of the exact dependencies included in it.
