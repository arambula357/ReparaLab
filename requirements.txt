# Requisitos de ReparaLab (candidato v1.0.0) (aplicación Java; este archivo no se instala con pip)
JDK 25 o posterior (Temurin 25 en CI)
Apache Maven 3.9.12 o posterior (para compilar y empaquetar)
MySQL Server 8.x (para ejecutar la demostración local)
Sistema de escritorio con interfaz gráfica y acceso a impresora para los flujos de impresión

# Configuración local requerida; los valores no deben subirse al repositorio
APP_DB_URL=jdbc:mysql://localhost:3306/reparalab_demo
APP_DB_USER=<usuario_local>
APP_DB_PASSWORD=<contraseña_local>

# Las bibliotecas Java y sus versiones se declaran en pom.xml.
